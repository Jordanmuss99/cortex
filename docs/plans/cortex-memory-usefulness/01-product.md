# Product: Cortex Memory You Can Trust

## Problem

Cortex remembers a great deal, but users cannot yet rely on it to capture every important fact, surface the right current context, or demonstrate that recalled memories improve the work. It can return stale information, appear active while learning nothing new, and describe itself as healthy without detecting the failures that matter. Users need Cortex to remember the right things, forget safely, and make the agent measurably more effective without introducing misleading context.

## Success metric

On a locked evaluation set of at least 200 real, memory-dependent Cortex tasks sampled from normal work, enabling Cortex increases successful task completion by at least 15 percentage points versus the same agent with memory disabled. Each task is judged against a prewritten human-scored success rubric, the evaluation is split by entire project or conversation to prevent leakage, and the result is reported with a 95% confidence interval.

## Announcement — the blog post before the feature

Cortex Memory You Can Trust turns past context into a dependable advantage instead of accumulated baggage. It reliably captures important facts, brings forward current and relevant context, and avoids distracting you with stale material. Its value is measured by whether memory improves real task outcomes, not merely whether something was stored or retrieved. You spend less time repeating yourself and correcting outdated assumptions, while Cortex remains predictable and transparent.
